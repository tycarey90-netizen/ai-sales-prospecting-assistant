# AI Sales Prospecting Assistant

An AI-powered prospecting helper for enterprise and mid-market account executives.

## What it does

- Takes a CSV of target accounts (company, industry, website).
- Uses an LLM to generate:
  - Company overview
  - Likely pain points
  - Discovery questions
  - Outreach angles
- Exports results to a CSV for use in your sales workflow.
